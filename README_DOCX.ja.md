# PDF to Word Converter

English version → [README_DOCX.md](README_DOCX.md)

## 概要

PDFファイルをWord（DOCX）に変換するPythonスクリプトです。

PDFの各ページを画像化し、Wordの各ページの背面に配置します。

PDFの原稿サイズを取得し、Wordの用紙サイズに反映します。

PDFのレイアウトや日本語文字の表示を維持したまま、Word上で文字や図形を追加できます。

## 主な機能

- PDFの1ページをWordの1ページに変換
- 複数ページ対応
- PDFの原稿サイズを自動取得
- 元のPDFと同じ用紙サイズで出力
- PDFページ画像を文字の背面に配置
- ページごとに異なる背景画像を設定
- DPI指定による画像解像度の変更
- 出力ファイル名の指定
- INIファイルによる上書き制御
- 全ページの原稿サイズが同一であることを検証

## ファイル構成

- `pdf_to_docx.py`
- `pdf_converter_common.py`
- `pdf_to_docx.ini`（初回実行時に自動作成）

## 動作環境

- Python 3.8以上

## 必要なライブラリ

- pypdfium2
- python-docx
- Pillow

## インストール

プロジェクトのルートディレクトリで実行します。

### pipによるインストール

```cmd
python -m pip install -r requirements.txt
```

## 使用方法

### 基本変換

```cmd
python pdf_to_docx.py sample.pdf
```

入力PDFと同じフォルダに `sample.docx` を作成します。

### 出力ファイルの指定

```cmd
python pdf_to_docx.py sample.pdf -o output.docx
```

### 画像解像度の指定

デフォルトは300 DPIです。

```cmd
python pdf_to_docx.py sample.pdf --dpi 400
```

DPIを大きくすると画像が鮮明になりますが、出力ファイルのサイズも大きくなります。

## INIファイル

スクリプトと同じフォルダに `pdf_to_docx.ini` を配置します。

初回実行時に存在しない場合は自動作成します。

初期設定：

```ini
[DEFAULT]
overwrite = 0
```

### overwriteの設定

| 設定値 | 動作 |
|---|---|
| 0 | 出力ファイルが存在する場合はエラー。上書き禁止 |
| 1 | 出力ファイルが存在しても上書き許可 |

デフォルトは `overwrite = 0` です。

## Wordの背景画像について

各PDFページの画像をWordのヘッダー領域に配置し、ページを基準にした絶対位置を指定しています。

画像は文字の背面に配置されます。

これにより、Word上でPDF原稿に対する文字入力や図形追加が可能になります。

複数ページの場合も、ページごとに個別の画像を設定します。

## PDFのページサイズ

PDFのページサイズを取得し、Wordの用紙サイズに反映します。

すべてのページが同じ原稿サイズであることを条件とします。

1ページ目と異なるサイズのページが存在する場合は、エラー終了します。

## 注意事項

- PDFの文字自体はWordの編集可能なテキストにはなりません。
- PDFの文字・罫線・図形は画像として保持されます。
- Wordのヘッダー領域に画像を配置するため、ヘッダーの編集を行う場合は注意してください。
- Wordの表示や印刷環境によって画像位置が異なる場合があります。
- 出力ファイルサイズは指定したDPIによって変化します。
- PDFのページサイズが異なるファイルには対応していません。
- パスワード保護されたPDFは、別途解除が必要な場合があります。
- Wordの用紙サイズ制限を超えるPDFには対応できない場合があります。
